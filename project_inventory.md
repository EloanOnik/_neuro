# Инвентаризация и описание файлов проекта «Нейростримерша»

Ниже представлен полный список файлов проекта, которые задействованы в архитектуре и разработке, с подробным описанием назначения каждого из них.

---

## 📁 Корневые файлы и конфигурации

### 1. `main.py`
- **Назначение:** Главная точка входа в приложение. Инициализирует компоненты (TTSPlayer, Brain, TwitchChat), управляет циклом опроса очереди чата и передачей сообщений в мозг бота.

### 2. `requirements.txt`
- **Назначение:** Список зафиксированных внешних зависимостей Python (версии библиотек для работы с Ollama, Kokoro ONNX, sounddevice, PyYAML и др.).

### 3. `NEUROSTREAMER_PLAN.md`
- **Назначение:** Основной документ планирования разработки (MVP за 1-2 недели, V1 за 1-2 месяца, V2, архитектурная схема, жесткие ограничения и стек технологий).

### 4. `plan.txt`
- **Назначение:** Промежуточный анализ критических недочетов в коде и первоочередной список задач на рефакторинг.

---

## 🧠 Модуль ядра (`core/`)

### 5. `core/llm.py`
- **Назначение:** Клиент для взаимодействия с локальным сервером LLM (Ollama). Отвечает за ленивую инициализацию HTTP-клиентов, прогрев моделей (`load_model`/`load_stream_model`), выгрузку (`stop_client`) и потоковую генерацию токенов (`stream_ask_generator`).

### 6. `core/context.py`
- **Назначение:** Управление историей диалога (`ChatContext`). Реализовано на базе `deque` (фиксированная длина по умолчанию 10 сообщений) для хранения последних реплик пользователя и ассистента с целью передачи в промпт LLM.

### 7. `core/tts.py`
- **Назначение:** Низкоуровневый движок синтеза речи на базе `kokoro-onnx`. Синтезирует аудиопоток из текста и воспроизводит его в реальном времени через `sounddevice` на указанное аудиоустройство (например, виртуальный кабель VB-Cable для OBS).

### 8. `core/events.py`
- **Назначение:** Заготовка под единую шину событий (`EventBus`) для будущей асинхронной координации компонентов (в текущей версии закомментирована/не используется).

---

## ⚙️ Сервисы (`services/`)

### 9. `services/brain.py`
- **Назначение:** Главный «мозг» бота. Загружает системный промпт из `system.yaml`, управляет фоновой очередью запросов (`enqueue`), собирает промпт (система + контекст + новое сообщение), вызывает генерацию токенов у LLM, буферизует токены в предложения и отправляет их в TTSPlayer.

### 10. `services/tts_player.py`
- **Назначение:** Асинхронный проигрыватель речи (`TTSPlayer`). Создает фоновою очередь сообщений для озвучки, инициализирует `TextToSpeech` и последовательно воспроизводит поступающие фразы, не блокируя основной event loop.

---

## 🔌 Адаптеры (`adapters/`)

### 11. `adapters/chat/twitch.py`
- **Назначение:** Адаптер чата Twitch (`TwitchChat`). Подключается к IRC-серверу Twitch через TCP/SSL сокеты в отдельном фоновом потоке (`threading.Thread`), обрабатывает пинг-понг (`PING`/`PONG`), парсит сообщения через регулярные выражения и складывает их в потокобезопасную очередь `message_queue`.

---

## 🛡️ Фильтрация (`filter/`)

### 12. `filter/filter_twitch_chat.py`
- **Назначение:** Фильтрация входящих сообщений чата (`FilterTwitchChat`) по черному списку запрещенных слов (`banned_words`).

### 13. `filter/words.txt`
- **Назначение:** Текстовый файл для хранения списка запрещенных слов или стоп-слов модерации.

---

## 🔄 Пайплайн (`pipeline/`)

### 14. `pipeline/stream_loop.py`
- **Назначение:** Координатор (`StreamLoop`), предназначенный для связывания всех модулей воедино: опрос чата Twitch -> фильтрация -> передача в Brain -> генерация -> озвучка.

---

## 🛠️ Системные файлы и конфигурации (`system/`, `bugs/`)

### 15. `system/system.yaml`
- **Назначение:** Файл конфигурации личности персонажа (имя, возраст, роль, правила поведения, стиль речи, границы, параметры Ollama).

### 16. `bugs/bug_checklist.md`
- **Назначение:** Детальный чек-лист багов и недоработок по каждому файлу проекта с метками критичности.

### 17. `bugs/bug_review.md`
- **Назначение:** Сводный аналитический отчет по кодовой базе, оценке готовности к MVP и пошаговым рекомендациям.
